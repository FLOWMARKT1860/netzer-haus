# Home energy dashboard – terms and conditions

This application is a private, non-commercial tool used by a single person at home.

- Purpose: reads the battery charge level, electric range and charging status of the user's own Volvo (read-only, Energy API) to show them on a private home energy dashboard.
- Data is stored only on the user's own computer at home.
- Data is not shared with, sold to or published for any third party.
- No vehicle commands are sent.
- The user can revoke access at any time in the Volvo ID account settings.
